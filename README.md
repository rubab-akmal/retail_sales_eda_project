# Retail Sales Data Analysis (EDA)

An Exploratory Data Analysis (EDA) project built using Python to uncover key sales trends, product performance, and customer behavior insights from a retail dataset.

---

## Project Overview
This project processes and analyzes retail transaction data to help businesses understand revenue drivers, high-performing sales periods, and customer demographics using data visualization and statistical techniques.

---

## Tech Stack & Libraries
* **Python** 
* **Pandas & NumPy** (Data Cleaning & Manipulation)
* **Matplotlib & Seaborn** (Data Visualization & Heatmaps)
* **Jupyter Notebook** (Development Environment)
